Shareable Catalog Filters

November 15, 2026 · Take a filtered game list with you

Find and share games

  • Copy a link that opens the catalog with your search, category, sort order, and Play Together filter already selected.
  • Shared links include public catalog filters only. Favorites and playlists stay on your device.
  • Open a shared filter link on a Chromebook, phone, or another computer and keep browsing from there.

Daily streak leaderboard

  • Open the shared streak leaderboard directly from the Daily Pick card.
  • Added a custom calendar-and-flame badge for the daily streak podium.

Custom Game Playlists

November 15, 2026 · Build your own game shelves

Organize and browse

  • Create up to 12 named playlists with up to 100 catalog games in each.
  • Add or remove a game from one or more playlists right from its game card.
  • Rename or delete playlists, preview their saved titles, and filter the catalog to a playlist.
  • Export JSON backups and import them on another device. Imports merge by playlist name and only keep games from the local catalog.
  • Playlist names and game selections stay in local browser storage and can be cleared with site data.
  • The active playlist filter is remembered in the current tab session so it stays selected after refresh.
  • Playlist, favorite, rating, play-count, and streak changes refresh in other open Arcade Atlas tabs.

Popular Games & Discovery Update

November 15, 2026 · Player features and catalog improvements

Original mini-games

  • Paddle Clash, Sky Hop, Gem Maze, and Asteroid Rush: added four original keyboard-and-touch playable games with matching custom icons.

New game addition

  • Connect Four: added a two-player browser version from Bryan Braun's MIT-licensed project, retaining the original license and attribution.

Catalog verification

  • The Chromium audit removed six imports that failed local-resource or runtime checks: Paper.io 2, Duck Life 4, Doge Miner, Sandboxels, Tank Trouble, and Hide and Smash.
  • Basketball Stars and Crazy Tunnel 3D were not retained because the repository contains no clear redistribution license for either third-party game.

New feature

  • Arcade Quests: earn 10 XP for each of your first three different game launches each day, plus a 25 XP daily goal bonus and one-time badges for exploring 5, 20, and 50 unique games, plus Party Starter for trying three different multiplayer games. Progress is stored on this device; launches do not verify completion.
  • Catalog links: removed nine off-site launch cards that had no playable build in the repository. The catalog now only launches locally hosted game paths.
  • Play More Like This: the home page now recommends matching local games from your favorites and four- or five-star ratings, or from games you repeatedly play. Suggestions update as your preferences change and stay on this device.
  • Favorites-only filter: filter the catalog to starred games, keep that choice between visits, and hide the Most Played shelf while active.
  • Accessible favorite controls: favorite stars are keyboard-operable buttons with screen-reader labels and larger touch targets.
  • Most Played on This Device: a new shelf ranks up to eight games by how often they have been launched on the current device. It updates automatically as games are opened.
  • Daily Pick: highlights one rotating game each day and tracks a local daily launch streak. You can submit new personal-best streaks to a shared public leaderboard with a nickname.
  • Quick category filters: added one-tap category chips that stay synchronized with the category dropdown and search results.
  • Search and tags: search now includes game descriptions and tags, and a Play together filter collects local couch co-op games.
  • Your ratings: rate games from one to five stars on this device, then sort by your personal ratings. Ratings stay in this browser and are not shared.
  • Game descriptions: added clear descriptions to 24 popular catalog games.
  • Catalog cleanup: the browser audit found Ancient Beast's required local files were missing, so its broken catalog entry was removed.
  • Blocky Combat SWAT playtime: the game page saves cumulative visible playtime locally between restarts and periodically submits play sessions to the shared leaderboard when configured.

Arcade Atlas Update

November 10–13, 2026 · Latest updates

New games

  • Hextris, A Dark Room, Untrusted, HexGL, Bitburner, and BananaBread: added launch cards for the authentic browser builds, with a direct link to each upstream GitHub repository.
  • Source verification: selected the projects' real repositories and original playable pages instead of similarly named copies or imitation games.
  • Leaderboard note: these upstream games do not expose a compatible Arcade Atlas score-submission interface, so shared leaderboard support is not enabled for them yet.
  • Brotato: Abyssal Terrors added as a playable web game, with its required game files imported automatically.
  • Volley Random added using the working HTML game loader.
  • Rooftop Snipers 2 added to the game catalog and its Unity loading, keyboard focus, and Poki-to-Unity startup communication were improved.
  • Stacktris updated to use the uploaded game files.

Leaderboard upgrades

  • Stacktris: connected the game to the shared leaderboard and improved score recognition with higher-resolution OCR, centered capture, alternate text recognition, and better handling of swipe animations.
  • Slope: restored the original Unity version of the game and improved end-screen score detection.
  • Slope anti-cheat: scores must be detected from the live game canvas after gameplay movement and an end screen; OCR must read the same score in two separate frames with at least 55% confidence. Text-only OCR guesses are rejected, and scores above 1,500 are blocked.
  • Block Blast: added OCR-based score submission that checks for the game-over screen and filters moving confetti from the capture.
  • Retro Bowl: added playtime tracking in days, hours, minutes, and seconds, and made total playtime appear on the leaderboard.
  • Player names: improved the name prompt used when submitting scores and playtime.

Site improvements

  • Added a Privacy Policy explaining leaderboard data, local storage, third-party games, and advertising.
  • Linked the Privacy Policy from the site footer.
  • Removed the extra ad placements and kept the Google AdSense integration.

More games added

  • Breakout: imported a complete playable HTML5 Breakout game, including its levels, gameplay code, styling, and score-submission hook.
  • 1v1.LOL: added a community-revived version of the game to the catalog.

Leaderboard and gameplay fixes

  • Top-player podium: redesigned leaderboard game sections to show the top three distinct players on a podium, with first place centered.
  • Reaction Test: corrected score sorting so the fastest reaction times rank highest.
  • Slope: made death detection react faster so the end-of-game score prompt appears sooner.
  • Breakout: connected game-over scores to the shared Arcade Atlas leaderboard.
