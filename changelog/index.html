Modern Games Update

November 13, 2026 · Modern 3D and Unity WebGL additions

New games

  • Arcade 3D: added the official browser build with five modes: open-world exploration, team deathmatch, battle royale, destruction sandbox, and a rocket mission.
  • Nightmaze: added the original Unity 6 first-person escape-horror game using its published WebGL build.
  • Cube Libre: added the original browser-based WebGL 2 3D survival/puzzle game.
  • The Clash of Civilizations: added the developer's Unity WebGL real-time strategy demo. Its online matches depend on the upstream Photon service.
  • Source checks: verified each GitHub repository, its documented official play URL, and the presence of the published browser build before listing it.
  • Quake III Arena (Q3JS): added the modern WebAssembly/ioquake3 browser port with live server selection, linking to the maintainer's source repository. The hosted Q3JS site supplies demo data; it is a fan project, not an official id Software service.
  • Leaderboard note: these games do not currently expose an Arcade Atlas-compatible score submission interface, so no shared leaderboard was added.

Arcade Atlas Update

November 10–13, 2026 · Latest updates

New games

  • Hextris, A Dark Room, Untrusted, HexGL, Bitburner, and BananaBread: added launch cards for the authentic browser builds, with a direct link to each upstream GitHub repository.
  • Source verification: selected the projects' real repositories and original playable pages instead of similarly named copies or imitation games.
  • Leaderboard note: these upstream games do not expose a compatible Arcade Atlas score-submission interface, so shared leaderboard support is not enabled for them yet.
  • Brotato: Abyssal Terrors added as a playable web game, with its required game files imported automatically.
  • Volley Random added using the working HTML game loader.
  • Rooftop Snipers 2 added to the game catalog and its Unity loading, keyboard focus, and Poki-to-Unity startup communication were improved.
  • Stacktris updated to use the uploaded game files.

Leaderboard upgrades

  • Stacktris: connected the game to the shared leaderboard and improved score recognition with higher-resolution OCR, centered capture, alternate text recognition, and better handling of swipe animations.
  • Slope: restored the original Unity version of the game and improved end-screen score detection.
  • Slope anti-cheat: scores must be detected from the live game canvas after gameplay movement and an end screen; OCR must read the same score in two separate frames with at least 55% confidence. Text-only OCR guesses are rejected, and scores above 1,500 are blocked.
  • Block Blast: added OCR-based score submission that checks for the game-over screen and filters moving confetti from the capture.
  • Retro Bowl: added playtime tracking in days, hours, minutes, and seconds, and made total playtime appear on the leaderboard.
  • Player names: improved the name prompt used when submitting scores and playtime.

Site improvements

  • Added a Privacy Policy explaining leaderboard data, local storage, third-party games, and advertising.
  • Linked the Privacy Policy from the site footer.
  • Removed the extra ad placements and kept the Google AdSense integration.

More games added

  • Breakout: imported a complete playable HTML5 Breakout game, including its levels, gameplay code, styling, and score-submission hook.
  • 1v1.LOL: added a community-revived version of the game to the catalog.

Leaderboard and gameplay fixes

  • Top-player podium: redesigned leaderboard game sections to show the top three distinct players on a podium, with first place centered.
  • Reaction Test: corrected score sorting so the fastest reaction times rank highest.
  • Slope: made death detection react faster so the end-of-game score prompt appears sooner.
  • Breakout: connected game-over scores to the shared Arcade Atlas leaderboard.
